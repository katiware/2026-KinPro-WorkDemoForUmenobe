# 🎮 Godot 2D ゲーム制作デモ (KinPro 2026)

新入生が2Dアクションゲームやミニゲームを制作する際のベースとなる **「2D Crystal Runner」** デモプロジェクトです。

Godot Engine 4.x の標準機能のみで構築されており、ノード構造・GDScript・シグナル連携が直感的で改造しやすくなっています。

---

## 🕹️ ゲームの遊び方 & 操作方法

| キー操作 | アクション |
| :--- | :--- |
| **`A` / `D`** または **`←` / `→`** | 左右移動 |
| **`SPACE`** / **`W`** / **`↑`** | ジャンプ |
| **`R`** | いつでもリスタート |

### 🎯 ルール
- 制限時間（45秒）以内に、ステージ内のコインを集めながら右端のゴール（緑の旗）を目指します。
- 動くトラップ（赤い四角）に触れるか、穴に落ちるとゲームオーバーになります。
- ゴールすると、集めたコインのスコアに加え、残り時間ボーナスが加算されます！

## 📂 プロジェクト構成

```
godot_demo/
├── project.godot       # Godot 4.x プロジェクト設定ファイル
├── scenes/
│   ├── main.tscn       # メインステージ（足場、コイン、敵、ゴール、UIを配置）
│   ├── player.tscn     # プレイヤーキャラクター
│   ├── coin.tscn       # 収集アイテム（ふわふわ浮遊アニメーション付き）
│   ├── obstacle.tscn   # 往復パトロールするトラップ
│   ├── goal.tscn       # ゴールフラグ
│   └── ui.tscn         # HUD（スコア、コイン、残り時間、リザルト画面）
└── scripts/
    ├── game_manager.gd # スコア、タイマー、ゲーム状態の管理
    ├── player.gd       # プレイヤーの移動、重力、ジャンプ、死亡判定
    ├── coin.gd         # コインの取得検知と浮遊
    ├── obstacle.gd     # 敵・トラップのパトロール移動
    ├── goal.gd         # ゴール到達判定
    └── ui.gd           # UIの描画更新とリトライボタン処理
```

## 🚀 起動手順

1. [Godot Engine 4 (Standard 64-bit)](https://godotengine.org/download/) をダウンロード・解凍します。
2. `Godot_v4.x.x_win64.exe` を起動します。
3. プロジェクトマネージャーの **「インポート (Import)」** を押し、本フォルダ内の `project.godot` を選択します。
4. 「インポートして編集」をクリックするとエディタが開きます。
5. 右上の **再生ボタン (▶)** または **`F5` キー** を押すとゲームが起動します！

## 💡 新入生向け改造アイデア

- **プレイヤーの強化**: `player.gd` の `speed` や `jump_velocity` を変更して2段ジャンプを実装してみよう！
- **新しい敵の追加**: `obstacle.tscn` を複製して、上下に動くトゲや高速で突進する敵を作ってみよう！
- **ステージの拡張**: `main.tscn` の足場（Platform）をコピペして、より長い立体的なアスレチックステージを作ってみよう！
- **グラフィックの差し替え**: `ColorRect` を `Sprite2D` や `AnimatedSprite2D` に差し替えてドット絵キャラクターを動かしてみよう！
