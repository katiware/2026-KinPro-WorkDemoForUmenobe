# 🚀 Streamlit Webアプリケーション作品制作デモ (KinPro 2026)

新入生がWeb作品やデータ分析・ゲーム制作支援ツールを作る際のモデルケースとなる **「Game Dynamics & Balance Simulator」** デモです。

Pythonコードだけで、モダンなUI、動的パラメータ変更、Plotlyによる高度なグラフ描画、AIシミュレーションなどを実装しています。

---

## 🌟 実装されている主な機能

1. **📈 物理軌道シミュレータ**:
   - プレイヤーの移動速度、重力、ジャンプ初速、空気抵抗をスライダーで操作
   - ジャンプ弾道（放物線）や最高到達点、滞空時間をリアルタイムに再計算してグラフ描画
2. **🗺️ ステージ設計 & 難易度分析**:
   - ステージ長やコイン密度、敵・トラップ数に応じたステージ俯瞰マップの自動生成
   - 物理パラメータと配置数からステージクリア難易度（0〜100）を自動算出
3. **🤖 AIエージェント自動攻略 (モンテカルロ法)**:
   - 設定したステージをAIボットが100回テストプレイ
   - クリア率、平均クリアタイム、獲得スコアの分布ヒストグラムを表示
4. **💾 設定エクスポート**:
   - 調整したパラメータを **Godot 4 GDScript** や **JSON** 形式でワンクリック出力

---

## 🛠️ 起動手順

### 1. 依存ライブラリのインストール
```bash
cd streamlit_demo
pip install -r requirements.txt
```

### 2. アプリの起動
```bash
streamlit run app.py
```
👉 コマンド実行後、ブラウザが自動起動し `http://localhost:8501` でアプリが表示されます。
