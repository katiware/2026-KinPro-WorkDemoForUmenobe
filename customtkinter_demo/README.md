# 🖥️ CustomTkinter デスクトップアプリ制作デモ (KinPro 2026)

新入生がPythonで **モダンで洗練されたデスクトップGUIアプリケーション** を制作するためのデモプロジェクトです。

標準のTkinterをベースに、ダークモード対応、美しい角丸デザイン、スムーズなアニメーションが簡単に作れる `customtkinter` を採用しています。

---

## 🌟 主な実装機能

1. **📊 プロジェクト管理ダッシュボード**:
   - KPIカード（進行中作品数、平均進捗、残り日数）
   - プログレスバー付きのスクロール可能なプロジェクト一覧
   - ダイアログによる新規プロジェクト追加機能
2. **📝 エディタ & クリエイティブツール**:
   - テキスト/コード編集エリア
   - ファイルの開く/保存ダイアログ連携
   - リアルタイム文字数・行数・単語数カウント機能
3. **⚙️ 外観 & テーマカスタマイズ**:
   - **ダークモード / ライトモード / システム連動** の即時切り替え
   - **UI拡大率（80% / 100% / 120%）** の動的変更
   - カラーテーマ（blue, dark-blue, green）変更

---

## 🚀 起動手順

### 1. 依存パッケージのインストール
```bash
cd customtkinter_demo
pip install -r requirements.txt
```

### 2. デスクトップアプリの起動
```bash
python app.py
```
👉 Windows上でモダンなデスクトップウィンドウが立ち上がります！

---

## 📦 単一の .exe ファイルに変換して配布する方法 (PyInstaller)

制作したデスクトップアプリは、Pythonが入っていないWindows PCでもダブルクリックで動くように **`.exe` 実行ファイル** に変換できます。

```bash
# PyInstaller をインストール
pip install pyinstaller

# 単一の .exe にビルド（コンソール非表示）
pyinstaller --noconsole --onefile app.py
```
ビルドが完了すると、`dist/` フォルダの中に `app.exe` が生成されます！
新入生同士で作品を交換したり、祭りで展示する際にとても便利です。
